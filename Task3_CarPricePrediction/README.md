# Task 3 — Car Price Prediction

Built regression models to predict used car selling price based on brand, age, 
mileage, fuel type, and transmission, using data cleaning and feature engineering 
(extracted brand from car name, calculated car age from year).

**Best Model:** Random Forest Regressor
**Key Insight:** Transmission type, car age, and km_driven are the strongest 
predictors of selling price.
**Dataset:** Vehicle dataset from CarDekho (Kaggle)
